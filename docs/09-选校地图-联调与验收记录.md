### 第 3 / 5 条为什么是黄灯

语境条（"来自现场全景 · 清除"）**故意不在服务端渲染**：URL 查询串走
`useSyncExternalStore`，服务端快照返回空串，客户端 hydration 后立刻补上。
这样 `/colleges` 才能保持静态预渲染（`○`），代价是语境条会晚一帧出现。

所以：

- **能自动验的部分**（参数解析、文案、无参数时不渲染）已经验了；
- **需要通过浏览器点的部分**（点入口 → URL 带参数 → 点清除 → 后退一次回到来源页）
  留给现场走查。

## 五、实施过程中发现并处理的方案问题

以下五处是**方案与实现之间必须做的判断**，都记在这里，避免下次重新讨论。

### 5.1 §6.15 说"单语字段的说明写进第 2 / 13 / 14 节"——位置写错了

第 2 节是区位、第 13 节是气质、第 14 节是点评，这三处**源数据是中英双份**
（`cz`/`ce`、`tz`/`te`、`nz`/`ne`），英文模式下本来就切得干净，不需要说明。

真正的单语字段在这三节：

| 单语字段 | 渲染位置 |
| --- | --- |
| `idef_t`（国际生认定原文） | 第 9 节「本科国际生比例」内 |
| `ivw_t`（面试政策概括） | 第 11 节「面试政策」内 |
| `essays`（文书提炼） | 第 12 节「小文书」内 |

**实现按实际位置加说明行**（英文模式下显示中文原文 + 一行
"This section comes from Chinese-only source data and is shown in Chinese."）。
`docs/08` §6.15 那句"第 2 / 13 / 14 节"应作废。

### 5.2 `alert`（政策提醒）在 15 节里没有归处

`alert` 是字段契约里的一列（全库仅 4 所有，例如"2027-28 申请季起恢复要求提交标化"），
但 `docs/06` 的 15 节里没有它该待的地方。

**实现**：放在档案头部校名下方，作为一行提示，只有有值时才出现。
这样既不插进 15 节的顺序里，也不会让这条信息消失。

### 5.3 点位散开的算法与方案描述不同

§6.5 写的是"以簇质心为中心，按距离从小到大依次外推"。实现改成**成对松弛**：
对屏幕距离小于 12px 的点对各退一半，迭代到没有冲突或位移触到 24px 上限。

**理由**：质心外推会整体搬动整簇，让整片密集区偏离真实地理位置；成对松弛只动冲突的两个点，
且同样满足"间距不小于 12px，或外推不超过 24px"这条验收标准。

**没有变的**：散开只改渲染坐标，拾取一律用原始 `x`/`y`（§6.5 的关键坑），有专门单测。

### 5.4 目录清单与实现的两处出入

| 方案 §5.1 写的 | 实际 |
| --- | --- |
| `export-shortlist.ts` | `export-shortlist.tsx` —— 它是个 React 组件，不是纯函数 |
| `colleges-detail.tsx` | **未单独建文件**。侧栏三段布局只有 20 行 JSX，直接写在 `app/colleges/page.tsx` 里，单独开文件反而多一层跳转 |

### 5.5 州名标注缺 DE / RI / DC 是沿用，不是漏做

底图 48 条州名标注里没有 DE、RI、DC —— 因为这三个州太小，放不下标签。
这是参考实现的取舍，`docs/08` §6.4 已登记。**这三个州里的院校点照常渲染**，
底图也照常画，只是没有州名文字。

| # | 现象 | 根因 | 修法 |

| 1 | 美国与周边国家没有视觉层次 | 根本没画邻国，也没有任何层级信号 | 引进参考实现同样的分层：海洋矩形 → 邻国陆地（加拿大 / 墨西哥 / 巴哈马 / 古巴）→ 美国本土；**美国这一整组加 `drop-shadow`**，把它从邻国上抬起来 |
| 2 | 阿拉斯加没有呈现 | M1 时 `SKIP_STATES` 把 AK / HI 跳过了（当时理由是"投影会落到画布外，参考实现也画不出来"） | 改用**插图区**方案：从参考实现取出 AK / HI 的几何，用 `transform` 平移缩放到左下角。**没有照抄参考实现的缺陷**——它那里的阿拉斯加左边被画布裁掉了（min x = -57），我们右移 57 并缩到 0.86，让整块完整可见；夏威夷再右移 20 避开 |

### 关键取舍

- **为什么从参考实现取那 6 块陆地**：加拿大 / 墨西哥 / 巴哈马 / 古巴 / AK / HI 在公开的
  美国州界数据里没有；要么再引一份世界地图数据（新依赖 + 新投影），要么自己给 AK / HI
  定插图投影手调参数。而参考实现里这 6 块**已经是同一套投影下的 viewBox 坐标**，
  取用最省事也最忠实。取法是按**包围盒**识别（那 57 条 path 没有 id / class / data-*），
  规则和结果都写进 `data/us-land.json`，另有一次性脚本 `scripts/extract-us-land.ts` 留档。
- **为什么用 CSS `drop-shadow` 而不是 SVG `<filter>`**：色值可以留在 `globals.css`，
  组件里不出现字面量色值（配色守卫测试会拦）。
- **没有画波多黎各等属地**：一期没有院校在那里，也不在地图叙事范围内。

### 新增的守卫

  加拿大压在画布上方 / 墨西哥伸到下方、**AK 与 HI 变换后完整落在画布内且互不相交**、

### 第四轮反馈：海洋渐变露接缝 + 靠边的学校点不中

这两条**是同一个根因**：SVG 元素盒子与 viewBox(975:610) 的宽高比不一致时，
`preserveAspectRatio="xMidYMid meet"` 会等比缩放后居中，左右留白。留白区不属于 viewBox：

- 留白区显示的是容器底色，而内容区是渐变 → 左右两条竖直接缝（用户红框的位置）；
- 坐标换算没扣掉留白 → 换算偏移 `|54.9 − 0.1125x|`，超出拾取阈值 15.6 后点不中，
  反推 **x < 349 与 x > 626 的院校全部点不中**（西海岸 + 东海岸），
  只有中间大平原那一条能点 —— 正好对应用户截图里左右两端的红框。

修法：

1. **海洋改成单一颜色**，且与容器底色取同一个值 → 接缝在物理上不存在；
2. 地图里所有「屏幕坐标 ↔ viewBox 坐标」的换算改走 `mapRect()`（扣掉留白的**内容区**），
   涉及拾取、悬停、滚轮缩放锚点、拖拽增量、点位散开的像素阈值。

守护：`colleges-map.test.tsx` 把元素盒子的宽高比刻意设成 **1200:500**（左右各留白 200px），
断言最靠左的院校（x < 60）也点得中。**这条能证伪**：把 `mapRect()` 换回
`svg.getBoundingClientRect()`，测试立刻挂掉 2 条（已实测）。

### 第五轮反馈：详情栏不再常驻

原来的版面是「左地图 62% + 右详情栏 38%」**常驻**，两个视图都是。问题是：

- 地图视图一进来就被挤掉 38% 宽，可这时候还没选任何学校，右边是空的；
- 表格视图右边也杵着一个空栏，把 23 列的表格挤得更窄。

改成按状态决定：

| 视图 | 选中了院校 | 版面 |
| --- | --- | --- |
| 地图 | 否 | 地图铺满整行（`h-[70vh]`） |
| 地图 | 是 | 左地图 62% + 右详情 38%，两栏同高同底（`h-[58vh]`） |
| 表格 | — | 表格铺满整行，**不出详情栏**（点行仍切回地图并打开详情） |

**连带问题与解法**：对比位托盘原来长在详情栏顶部，详情栏一收，已收集的学校就没地方显示了。
规则改成 —— 详情栏收起时（含表格视图），只要对比位里有学校，就把托盘渲染到内容区上方。
收集到的东西任何时候都不会消失。点托盘里的槽仍会把那一所切回浏览位（在地图视图里即打开详情栏）。

顺带一处：工具栏的**搜索联想**在表格视图里点了原本没有任何可见反应（详情栏不出现），
现在点联想会先切回地图视图再打开详情栏 —— 语义就是"我要去看这所学校"。

**守护**：新增 `src/app/colleges/__tests__/page.test.tsx`（4 条，第一次给页面级行为上锁），
断言的就是上面这张表的每一行：

1. 地图视图默认没有 `.colleges-split`、没有对比托盘、没有详情栏空态；
2. 点圆点后出现 `.colleges-split` + 右侧详情（第 1 节「排名」渲染出来）；
3. 切表格视图后 `.colleges-split` 消失、详情栏消失、表格还在；
4. 加入对比后再收起详情栏 → `<aside>` 消失但托盘仍在（挪到了内容区上方）。

另外服务端渲染（默认没选中）的 HTML 也核过：没有详情栏、没有托盘、没有 grid class。
