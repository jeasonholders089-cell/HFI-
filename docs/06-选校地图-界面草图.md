## 七、加入对比：收集与查看

### 7.1 先看原版的链路（它本来就是对的）

原版**把"浏览"和"收集"分成了两套东西**，这一点没坏：

| 角色 | 原版的容器 | 一次显示 | 生命周期 |
| --- | --- | --- | --- |
| 浏览 | 地图右上角浮层小卡 | 一所 | 点另一所学校就被整体替换 |
| 收集 | 屏幕底部黑色对比条 | 已选的全部（最多 3 所） | 一直留着，直到清空 |

链路上是四步：点地图圆点 → 浮层小卡出现 → 点「⚖ 加入对比」→ 底部黑条浮出，
装着已选的学校，每所有一个 ✕；凑够 2 所以上，黑条上出现「查看对比」→ 点开全屏对比表。

### 7.2 固定侧栏带来的唯一变化

你说得对：详情栏固定之后，点地图上另一个圆点，就是在右侧栏里**整体切换**内容。

但这**不会影响对比逻辑**——因为对比清单本来就不住在浏览卡片里，它住在另一个容器里。
唯一要解决的是：原来那个容器（屏幕底部黑条）我们不要了，得给对比清单找一个新的家。

### 7.3 新家：侧栏顶部的对比位

放在侧栏顶部，不放工具栏。四个理由：

1. 对比是"看着地图挑学校"这个动作的产物，它属于地图区，不属于全局工具栏；
2. 反馈贴着操作点——刚点完「加入对比」，眼睛就在侧栏，托盘里立刻多一个槽；
3. 工具栏已经有 5 个筛选器 + 搜索 + 视图切换 + 收藏 + 导出 + 清除筛选，再加一个就挤了；
4. 托盘里能看到**校名**，工具栏上只能看到一个数字。

### 7.3.1 锁定项用什么形态：紧凑槽

**锁定项** = 已经点过「加入对比」的那几所学校。
它们**不展开成完整卡片**，而是压成一个只显示校名和 ✕ 的小标签，一行放得下三个。

叫"槽"是因为位置固定三个，空着的显示成 `[ 空 ]`，像一排停车位。

【一】锁定的每一所都展开成完整卡片，并排（占满整排宽度，且字段对不齐）

```
  ┌────────────────────────┐ ┌────────────────────────┐ ┌────────────────────────┐
  │  莱斯大学    ✕         │ │  纽约大学    ✕         │ │  卡内基梅隆  ✕         │
  │  Rice University       │ │  New York University   │ │  Carnegie Mellon       │
  │  ----------------      │ │  ----------------      │ │  ----------------      │
  │  1  排名               │ │  1  排名               │ │  1  排名               │
  │  2  所在城市与州       │ │  2  所在城市与州       │ │  2  所在城市与州       │
  │  3  学费(不含食宿)     │ │  3  学费(不含食宿)     │ │  3  学费(不含食宿)     │
  │  ...  共 15 节         │ │  ...  共 15 节         │ │  ...  共 15 节         │
  └────────────────────────┘ └────────────────────────┘ └────────────────────────┘
```

【二】锁定项压成紧凑槽：只占一行，浏览位留一所完整详情

```
  ┌────────────────────────────────┐
  │  ⚖ 对比位 (2/3)      [ 清空 ]  │
  │  [莱斯 ✕] [纽大 ✕] [ 空 ]      │
  │────────────────────────────────│
  │  浏览位                        │
  │                                │
  │  纽约大学  私立综合            │
  │  New York University           │
  │  --------------------------    │
  │  1  排名                       │
  │  2  所在城市与州               │
  │  ...  共 15 节，顺序不变       │
  │                                │
  │  [ 查看详情 ] [ ⚖ 已在对比位 ] │
  │  [ 并排对比 (2) → ]            │
  └────────────────────────────────┘
```

三个直接后果：

| 后果 | 说明 |
| --- | --- |
| 省地方 | 三个标签占一行（约 40px 高）；三张完整卡片要占一整排宽度（约 1200px） |
| 一眼分得清 | 标签形态与浏览位的完整详情完全不同，扫一眼就知道哪几所在对比；若都是完整卡片，就只能靠"右上角有没有 ✕"判断，信号太弱 |
| 标签可点 | 点某个标签，那一所的完整详情就回到浏览位；槽既是收集箱，也是切回某所学校的快捷入口 |

**对比本身不是靠这几个标签看的。** 标签只表示"这几所已被选中"。
真正逐行对齐比较，还是点「并排对比」打开对比表——见 7.6。

### 7.4 完整状态

| # | 状态 | 侧栏 | 对比托盘 | 地图 |
| --- | --- | --- | --- | --- |
| 1 | 未选中 | 空态：点地图上的圆点，查看院校详情 | 3 个空槽 + 一句提示 | 圆点常态 |
| 2 | 选中一所 | 该校信息 | 空槽不变 | 该圆点加描边 |
| 3 | 加入一所 | 按钮变「⚖ 已在对比位」 | 空槽填入校名 | — |
| 4 | 换个圆点 | **整体换成另一所** | **保持不变** | 描边移到新圆点 |
| 5 | 满 3 所 | 其余学校的按钮置灰：对比位已满 | 空槽消失 | — |
| 6 | ≥2 所 | 托盘出现「开始对比」 | 同上 | — |
| 7 | 看对比 | 打开全屏对比表 | 不变 | 不变 |

**第 4 行是整个设计的重点**：换个圆点只切换浏览目标，托盘里已经挑好的几所不会被清掉。
这就是把"浏览"和"收集"分开的意义。

### 7.5 三种状态

### 7.6 对比表：仍然是浮窗

点「并排对比」打开一个浮窗。三个理由：

1. 对比是"看一眼就走"的动作，浮窗最轻——关闭即恢复，地图和侧栏的状态完好不动；
2. 侧栏只有 380-450px，三列并排放不下，这是物理限制；
3. 若改成侧栏就地展开，侧栏要临时加宽到 860px：1920 屏上地图还剩 1000px 可以，但
   1440 笔记本上地图只剩 580px 就没法看了，而且侧栏会变成"三种宽度 x 两种内容"的状态组合。

**字段顺序照原样保留，不重排。**

原版对比表的行序：学校 · US News 2026 · QS世界 2026 · 城市/州 · 类型 · 整体录取率 ·
早申录取率 · RD录取率 · 早申杠杆 · 转学录取率 · 申请人数 · SAT中位50% · 平均GPA ·
标化政策 · 申请批次 · 截止(早申/RD) · 学费 · 国际生比例 · 国际生认定 · 面试政策 ·
男女比 · 院校气质 · 一句话点评

**要改的两处：**

| 项 | 原版 | 我们 |
| --- | --- | --- |
| 浮窗宽度 | 104 + 237 x 数量 + 46（2 所 624px，3 所 861px） | 上限放宽到 92vw，三列各到约 380px；两所时不用撑满 |
| 手机端 | 按 96% 屏宽硬撑，三列各约 110px，读不动 | 第一列字段名冻结，右侧三列横向滚动 |

**要原样保留的一处（这是对比表的核心价值）：**

自动高亮每一行的最优值——**只有 8 行参与**：整体录取率、早申录取率、RD录取率、
**早申杠杆**、转学录取率、国际生比例取最高；申请人数、学费取最低；
**SAT 与 GPA 不参与**（源码里没有比较器）。并列则都不高亮。（源码里是 `best` 类。）
