# HFI 家长成长营 · 现场操作手册

> 给现场工作人员的「照着做就行」手册。**内容以 `src/` 的代码为准**（2026-09-17 逐条核对）。
> 活动前一天读第一、二、三节；活动当天只看第四、六节。

## 〇、先搞清楚三件事

1. **这份手册给谁**：只在现场服务的工作人员（志愿者、助教、老师）。
   家长不需要看它——家长只有 1 个动作：扫码，填表，提交。
2. **产品重心是成长探索，不是升学规划。** 院校和专业是让方向「看得见」的落点，
   不是要去考的目标。跟家长解释时不要滑向"怎么申上"。
3. **三条红线**（详见第七节）：不预测录取结果；大屏上不出现「姓名 + 画像」；
   AI 出问题不阻断数据入库。

## 一、一分钟看懂

### 1.1 产品在做什么

家长填一份八字段的问卷 → AI 给出 3 个发展方向并归到 8 类里 → 全部问卷匿名汇总后
在现场大屏呈现（地图、方向统计、院校名单、词云）。

```
兴趣特质 → 成长方向 → 方向通向哪里（专业 / 院校） → 地图
```

这条链条**任何一环断了，产品就不成立**。现场遇到问题先看链条断在哪一环。

### 1.2 两条并行的录入路径

| 路径 | 入口 | 使用者 | 设备 |
| --- | --- | --- | --- |
| A · 家长自助填写 | `/register`（扫码进入，零注册） | 家长 | 手机 |
| B · 工作人员录入 | 首页的批量录入（Excel / 文本） | 工作人员 | 电脑 |

### 1.3 页面清单（当前实际状态）

| 页面 | 地址 | 谁用 | 状态 |
| --- | --- | --- | --- |
| 首页 | `/` | 工作人员（批量录入、二维码） | 已建 |
| 家长自助填写 | `/register` | 家长（手机） | 已建 |
| 现场全景（大屏） | `/explore` | 大屏 + 工作人员 | 已建 |
| 选校地图 | `/colleges` | 家长 / 工作人员（大屏可放） | 已建 |
| 工作人员单条访谈录入 | `/entry` | — | **未建，现场别找** |
| 孩子成长画像 | `/child/[token]` | — | **未建，现场别找** |
| 提交成功页 | `/register/success` | — | **未建，提交后就地变「感谢你的分享。」** |

### 1.4 页面顶部的导航

四个页面共用同一条导航：`关于活动` · `探索全景` · `选校地图` · `工作人员入口`。

> 这条导航**只在屏幕宽度 ≥ 768px 显示**。家长手机上看不到它，也不需要——
> 家长只需要填表，别在电话里让家长"点上面的导航"。

## 二、活动开始前（T-1 到开场前 15 分钟）

### 2.1 检查清单

- □ **站点能打开**：首页出现「让每个孩子的**可能性** 被看见。」
- □ **数据库通了**：浏览器访问 `/api/health`，返回 `{"ok":true}`
- □ **大屏机器**：Chrome 打开 `/explore` → F11 全屏 → 关闭系统休眠 / 屏保 → 页面缩放 100%
- □ **二维码用正式域名生成**：见 §2.3
- □ **清掉上一场的残留数据**：见 §4.9（按钮目前在 `/explore` 标题行右侧）
- □ **试跑一条**：现场随手填一条真问卷，确认大屏 45 秒内出现（这就是彩排）

### 2.2 大屏建议

- 大屏用 `/explore`，**不要**用首页——首页那排数字（参与家庭 / 梦想院校 / 发展方向）
  目前是**占位符 X，没有接数据**，别在大屏上用它。
- `/colleges` 可以单独开一个标签页备用（问院校的时候切过去），但它和现场数据无关，
  是 113 所院校的静态地图。
- 大屏页面每 45 秒自动刷新一次，**不需要人手点**。看到标题行「更新于 HH:MM」在走，
  就说明大屏是活的。

### 2.3 二维码

首页 `工作人员入口` 区域 → 点「**生成手机问卷二维码**」→ 右侧出现二维码 →
直接截图/打印贴在签到台。

> **必须用正式域名打开首页再生成。** 二维码里编的是「当前这个网址 + `/register`」，
> 用 `localhost` 打开首页生成出来的二维码，家长扫码会打不开。

### 2.4 彩排（可选，仅限本地）

本机没有推理代理，走 `/api/children` 提交只会落库、AI 不会跑，大屏上「已生成画像」永远是 0。
想提前看大屏装满数据的样子，用演示数据脚本：

```bash
pnpm seed:demo                                  # 只预览：多少条、哪些学校、方向怎么分布
pnpm seed:demo -- --yes                         # 写入「今天」这一场
pnpm seed:demo -- --count=60 --yes              # 指定条数
pnpm seed:demo -- --clear-today --yes           # 先清掉今天这一场再重填
```

这些记录的方向是**脚本伪造的**（模拟「AI 已分析」），只为了让每个区块都有真实量级的内容。
**彩排完必须清干净再开场**（§4.9），否则大屏上会有假数据。

## 三、家长这一侧：填问卷（手机）

### 3.1 流程

扫码 → `/register` 页面 → 填八个字段 → 点「**提交成长档案　→**」→ 整页变成
「**感谢你的分享。**」+ 一句提示语 → 结束。

### 3.2 八个字段

| 字段 | 必填 | 说明 / 占位提示 |
| --- | --- | --- |
| 孩子的英文名 | 是 | 例如 Emma Wang。**是昵称性质，不要求真名** |
| 年龄 | 是 | 1–100 的整数 |
| 梦想学校 | 是 | 例如 RISD / Stanford |
| 兴趣 | 是 | 孩子感兴趣的领域 |
| 喜欢的活动 | 是 | 例如绘画、编程、辩论 |
| 孩子自我描述 | 是 | 请让孩子用自己的话描述 |
| 家长观察 | 是 | 你观察到的特点与闪光点 |
| 梦想职业 | 否 | 例如游戏设计师、建筑师 |

> **不采集真实姓名、手机号、微信、身份证、照片。** 现场不要把纸质表上的全名抄进系统。
> 表单里的「英文名」只当昵称用。

### 3.3 提交时的反馈（照着念给家长听）

| 页面显示 | 含义 | 工作人员该做什么 |
| --- | --- | --- |
| 「感谢你的分享。」+「问卷与 AI 画像已保存」 | 完全成功 | 无事 |
| 「问卷已入库，但 AI 分析未完成。工作人员可在活动全景点击开始分析。」 | 问卷**已保存**，只是 AI 那一步没过 | 在大屏上点「分析全部待分析孩子」 |
| 输入框下面标红「请填写×××」 | 有必填项没填 | 让家长补齐，第一次缺失的字段会自动聚焦 |
| 红字「…可以重试，同一次提交不会重复写入。」 | 网络或服务异常 | 让家长**点同一个按钮重试**，不会写重 |
| 「正在保存问卷并生成画像，请勿重复提交，保持页面打开。」 | 正在提交 | 提醒家长别刷新、别连点 |

### 3.4 三条容易被问到的

- **会不会重复？** 同一次提交带了唯一标识，反复点、断网重试都只会写一条。
  但**刷新页面后重新填一遍，就是新的一条**。
- **要不要注册？** 不要。没有账号、没有登录。
- **填完能看结果吗？** 孩子个人画像页 **还没做**（`/child/[token]` 未建）。
  现在能看的是现场大屏上的汇总，以及可以自己逛 `/colleges` 选校地图。

## 四、工作人员这一侧（电脑 / 大屏）

### 4.1 打开大屏

浏览器打开 `/explore`。这一页就是给大屏看的，六个区块从上到下：

| 区块 | 内容 |
| --- | --- |
| ① 标题行 | 标题 + 三个数字 + 「人数最多的方向」3 个标签 + 一排工作人员小按钮 |
| ② 梦想院校地图 | 圆点大小按人数分档，悬停看「校名 · N 人」 |
| ③ 发展方向统计 | 8 类条形图（每类带一行类目释义） |
| ④ 梦想院校完整名单 | 含未收录坐标的院校 |
| ⑤ 特质词云 | 需要手动生成，生成后落库缓存 |
| ⑥ 已录入的孩子 | 兴趣原文 + 画像状态 + 删除按钮 |

**标题行左边的三个数字**是判断现场进度的唯一入口：

| 数字 | 含义 |
| --- | --- |
| 已录入孩子 | 这一场收上来多少份问卷 |
| 已生成画像 | 其中 AI 已跑完的 |
| 待分析 | 还有多少条等着跑 AI |

### 4.2 标题行右侧的按钮（工作人员专用）

| 按钮 | 作用 | 什么时候点 |
| --- | --- | --- |
| 场次下拉 | 切换「今天 / 某个历史日期 / 全部场次」 | 复盘看历史；现场**不要动** |
| 更新于 HH:MM | 不是按钮，是自动刷新的时间戳 | 变红了说明自动刷新连续失败 3 次 |
| 分析全部待分析孩子 | 把所有还没跑的问卷**一条一条**跑 AI | 大屏「待分析」不为 0 时 |
| 刷新数据 | 立刻重新读一次数据 | 想马上看到刚提交的那条 |
| 清空孩子数据 | 清空整库（红框按钮） | 只在开场前和全场结束时 |

### 4.3 把访谈记录导进来（三条路径）

**路径 1 · 家长自助**：什么都不用做，家长提交后 45 秒内自动上大屏。

**路径 2 · 批量文本**：首页「试着描述你的孩子」卡片里的第一个输入框 →
「**批量文本入库**」。

```
Emma Wong
12
RISD
绘画 / 手工
绘画、做手账、学校美术社
我喜欢画小动物，也喜欢给同学做生日卡片
对细节特别在意，能安静画三个小时
插画师

Leo Chen
10
Stanford
编程 / 数学
搭乐高、写小游戏
…
```

规则（写错了会整批不导入）：

- **每个孩子一组，组与组之间空一行**；
- 组内**一行一个字段**（同一行用 Tab 分隔也可以）；
- 字段顺序固定：英文名 → 年龄 → 梦想学校 → 兴趣 → 喜欢的活动 → 孩子自我描述 → 家长观察 → 梦想职业；
- **前 7 项必填，第 8 项梦想职业可省略**；
- 年龄必须是 1–100 的整数；
- 字段里**不能换行**（换行会被当成下一个字段）。

**路径 3 · Excel**：同一个卡片里「上传 Excel」选文件 → 「**解析并入库**」。

- 只读**第一张表**；
- 第一行必须是表头，**列名用这八个英文名**（顺序随意，不用的列可以没有）：
  `englishName` `age` `dreamSchool` `interests` `activities` `selfDescription`
  `parentObservation` `dreamCareer`

导入成功提示「**已导入 N 条记录**」；失败会把「第几条缺了哪个字段」全部列出来，
并且**一条都不会写进去**，改完重传即可。

> 导入的是问卷原文，**不含 AI 画像**。导完要接着做 §4.4。

### 4.4 跑 AI 分析

点标题行的「**分析全部待分析孩子**」，或表格里某一条右边的「**开始分析**」。

- 任务是**一条一条串行**跑的，页面顶部会出现「正在分析 3/12（记录 #47），请保持页面打开。」
- 跑完提示「本次完成：成功 N 人，失败 M 人。失败记录可点击重试。」
- 失败的条目按钮会变成「**重试分析**」，红色文字写着失败原因，点一下即可重试。
- **跑的时候不要关页面、不要刷新**，也尽量别同时点别的按钮（AI 忙的时候其他按钮会自动禁用）。

> 经验值：一批 10–20 条比较稳。平台对每个用户同时只放行 3 个 AI 任务，
> 撞闸时系统会自动按 3s / 6s / 12s 退避重试——这是设计好的，不用你去点。

### 4.5 补八类分类（老数据）

如果 ③ 区块里出现一段提示「**N 位孩子的已有画像缺少八类标签，暂未计入统计**」，
说明这些记录是早期版本跑的（当时分类只有 4 类）。点提示里的「**AI 补全分类**」，
系统只重跑"归类"这一步，**不会重写已经给出的方向**。

### 4.6 生成特质词云

⑤ 区块右侧的「**生成**」按钮。

- 词云**只有点「生成」才会变**。生成一次就写进缓存，大屏刷新、切来切去都不会变；
  再点一次会变成「**重新生成**」，那时候词才会换。
- 最多显示 **12 个词**，字号按对应人数缩放。
- 词云**按场次隔离**：切到别的场次，这一场的词会立刻消失，改成显示那一场的缓存
  （没生成过就是空白，需要点生成）。
- 词云下面那行小字「基于生成时的 N 位孩子 · 时间」是提醒你：**数据变了要重新生成**。

> 词云是现调 AI 算的，同一个人数、同一批孩子，模型每次给的词都不一样——
> 所以要缓存。别因为"点了一下词没变"以为坏了。

### 4.7 删掉某一条

⑥ 区块表格最右边那一列的「**X**」按钮 → 浏览器弹确认框 → 确定。
只删这一条，其他孩子不受影响，**删了不可撤销**。

### 4.8 切场次（一天一场）

标题行的「场次」下拉，三个选项：

- 「今天（2026-09-17）」——**默认，大屏正常就停在这里**；
- 具体日期——只列**有数据**的场次（最多 30 个，最近的在前），用来复盘；
- 「全部场次」——不过滤，把所有历史混在一起看。

切下去之后，②③④⑤⑥ 五个区块会**同时**按这个口径重算。看到「历史场次 · 2026-09-16」
这行小字，就知道自己不在现场这一场了。

> **现场有一个坑**：如果有人为了"看看昨天"切到了历史场次，忘了切回来，
> 大屏就会一直显示昨天的数据，而且看起来一切正常。**开场前和每次交接班，
> 先确认标题行的场次标签写的是「今天的场次」。**

### 4.9 清空全部孩子数据

标题行右侧的红色「**清空孩子数据**」→ 弹窗 → 在输入框里**手打**
「清空孩子数据」四个字 → 点「**永久删除**」。

三条必须知道的：

- **不可撤销。** 会删掉库里**所有**孩子的问卷与 AI 画像，统计、地图、名单一起清零。
  跟"删除某一条"不是一回事，别点错。
- 弹窗里写着「请确认已备份需要的数据」——**现在没有一键导出问卷的功能**，
  需要备份请让技术同学从数据库导。
- 只有在同一站点页面里点才有效（跨站请求会被直接拒绝）。

> 位置说明：按产品决定，这个按钮**将来要挪回首页**（大屏是公开页面，
> 不该挂着清库按钮），目前仍在 `/explore`。挪动之后本手册要同步更新。

## 五、选校地图 `/colleges`

这一页**不查数据库、不发网络请求**，113 所院校的数据在构建期就编译进页面了，
所以在断网的现场也能用。它是"方向通向哪里"的落点，**不是升学规划工具**。

### 5.1 怎么进

- 顶部导航「选校地图」；
- 或从 `/explore` 最下方「进入选校地图 →」（会带一条语境条，见 §5.4）。

### 5.2 页面上的东西

| 位置 | 功能 |
| --- | --- |
| 地图视图 / 表格视图 | 两个视角随意切；表格适合快速扫数字。点表格行会**切回地图**并把它挪到视口中央 |
| 搜索框 | 输中英文校名，带下拉建议；点建议会直接打开那所学校的详情 |
| 五个筛选器 | 类型（综合大学 / 文理学院）、地区（东北 / 南部 / 中西部 / 西部）、申请批次、标化政策、排名（Top 30 / Top 50） |
| 洞察榜 | 5 个标签：早申倍数高 · 国际生占比高 · 转学率较高 · 申请池较小 · 不看标化（括号里是全库命中数） |
| 我的收藏 | 在院校卡片的星标里加入；「我的收藏（N）」只看收藏；星标 ≥ 6 所时下面会出现两条客观提示 |
| 导出清单 | 收藏 ≥ 1 所才出现 →「家庭选校清单」→「打印 / 存为 PDF」，A4 横向，带家庭备注栏 |
| SAT 初步区间 | 见 §5.3 |
| 对比位 | 最多放 3 所，两个以上才出现「并排对比」浮窗 |
| 字号 / 语言 | 右上角：字号三档 `A → A+ → A++`，语言按钮写着「English」 |
| 清除筛选 | 有筛选生效时才出现 |

地图操作：**滚轮缩放 · 拖拽平移 · 点击圆点看卡片**（这行提示就写在地图下方）。
图上四种点位：实心圆点 = 综合性大学，空心圆点 = 公立大学，菱形 = 文理学院，
小菱形 = 城市；图例在工具栏第一行右侧。滚过一屏后右下角会出现「回到顶部」。

手机上详情栏是**贴底抽屉**，默认收起，点底部那条深色条可以展开 / 收起；
对比位在详情栏收起时会自动挪到内容上方，收藏的东西不会丢。

### 5.3 黑马匹配（全站唯一的例外话术）

点「**SAT 初步区间**」输入一个 SAT 分数，地图上的院校会被标成四档：
**偏冲 / 冲·适中 / 适中 / 较稳**。

这是**全站唯一允许出现这类话术的地方**，而且必须同时满足三条，缺一不可：

1. **只出现在 `/colleges`**——首页、大屏 `/explore`、孩子画像页都不许出现；
2. **必须常驻显示局限说明**（它已经写死在页面上，不要用海报贴掉）；
3. **不许和某个孩子绑定**——不能出现"某个孩子的名字 + 档位"。

它只用了「SAT 中位区间 × 整体录取率」两个维度，**没算** GPA、课程难度、申请专业、
国际生身份、资助需求、批次，置信度低，**不构成录取预测或承诺**。
家长问起来，就这么说。

### 5.4 语境条

从别处带 `?from=...` 进来时，页面顶部会出现一条浅色说明（例如「来自现场全景」），
旁边写着「只提示，不筛数据」。它的作用是告诉你"从哪条链路来的"，
**不会**把院校按方向筛一遍——因为数据里根本没有"专业 ↔ 院校"的映射。
点右边的「清除」即可去掉。

## 六、异常速查（现场照着查）

| 现象 | 原因 | 你要做的 |
| --- | --- | --- |
| 家长提交了，大屏上没有 | 大屏是 **45 秒**自动刷一次，不是实时 | 等半分钟；着急就点「刷新数据」 |
| 「更新于 HH:MM」没变、或变成红字「数据可能已过期」 | 自动刷新连续失败 3 次，显示的是最后一次成功的数据 | 点「刷新数据」；仍然失败就检查网络/服务，别在台上继续操作 |
| 页面红字「暂时无法读取数据库，请点击刷新数据重试」 | 数据库或服务端不可达 | 点「刷新数据」重试；连续失败联系技术同学 |
| 「读取超过15秒，可能是预览服务或网络连接延迟…」 | 网络太慢 | 点「刷新数据」；已有数据不会丢 |
| AI 分析某条失败，按钮变「重试分析」 | 模型返回异常 / 撞并发闸 | 直接点「重试分析」，多数第二次就过 |
| 「模型返回的方向或依据不完整，请重试」 | AI 这次没按格式输出 | 同上，点重试 |
| 词云生成报错 | 模型输出无效（虚构了孩子 ID、给了重复词等） | 再点一次「生成」；连续失败就先跳过，别堵在现场 |
| 词云一点就变、每次都不一样 | **不该发生**——已落库缓存 | 确认没人连点「重新生成」；刷新页面看词是否稳定 |
| 5 米外看不清词云 | 字号和词数是现场反复调过的平衡 | 用浏览器放大（Ctrl + `+`）配合，不要改代码 |
| ③ 区块提示「N 位孩子的已有画像缺少八类标签」 | 早期 4 类时代的数据 | 点「AI 补全分类」 |
| 点了「清空孩子数据」输入对了字还是失败 | 弹窗里输入的不是完整六个字 | 手打「清空孩子数据」，一个字都不能少 |
| 点了删除弹 403 | 页面不是从本站打开的 | 从正式域名重新进 `/explore` 再删 |
| 大屏数据明显是昨天的 | 场次被切走了 | 把「场次」下拉切回「今天」 |
| `/colleges` 上"收藏"按钮变灰、提示存储不可用 | 浏览器禁用了本地存储 | 提示一次即降级：收藏只在本次会话有效，不影响看数据 |

**通用的三条纪律：**

1. **别刷页面。** 页面自己会刷新。
2. **失败先重试一次。** 绝大多数失败是模型输出格式问题，重试就过。数据不会因为失败丢。
3. **别在台上排查。** 大屏正在被家长看着时，用另一台设备处理；大屏保持干净。

## 七、不可逾越的红线（现场版）

这几条不是"最好别"，是**不能**：

1. **不预测录取结果**，不说"冲刺 / 匹配 / 保底"（唯一例外是 §5.3，且只在 `/colleges`）。
2. **不判定孩子适合什么。** 只给路径，不给结论。AI 的输出一律说成"探索性建议"。
3. **大屏上不出现「孩子姓名 + 个人画像」的组合。** 大屏只出现人数、方向、校名、特质词。
4. **不采集真实姓名、手机号、微信、身份证、照片。**
5. **六岁以下 / 未获家长知情同意，不采集、不分析、不展示。**
6. **删除类操作只在正式站内点**，不要用第三方工具直接打接口。

### 两条已知风险（一期已登记，未修）

- 大屏 ⑥ 区块会把问卷里的「**兴趣**」原文铺出来。它**没有姓名**，但自由文本里可能夹带
  学校、班级、老师、比赛等信息，等于绕过了第 3 条。**现场提醒家长：兴趣那一栏只写兴趣，
  不要写校名、班号和老师名字。** 这条二期随孩子画像页一起处理。
- 大屏背后的数据接口目前**没有脱敏**：打开浏览器开发者工具，理论上能拿到
  「英文名 → 方向」的配对。所以**大屏电脑不要交给家长操作**，也不要让无关的人碰键盘。

## 附录 A · 八个方向与类目释义

大屏 ③ 区块显示的 8 类，是**固定契约**（字符串与顺序都冻结），不再新增第 9 类：

| 类别 | 屏幕上跟着显示的释义 |
| --- | --- |
| 人文科学 | 例如：文学 / 历史 / 哲学 / 语言学 / 宗教 |
| 社会科学 | 例如：政治 / 社会学 / 心理 / 人类学 / 国际关系 / 新闻传播 |
| 商科与管理 | 例如：经济与金融 / 管理 / 创业 / 市场营销 / 会计 |
| 自然科学 | 例如：物理 / 化学 / 生物 / 地球与海洋 / 天文 / 环境 |
| 数学与计算 | 例如：数学 / 统计 / 数据科学 / 计算机 / 人工智能 |
| 工程与应用 | 例如：机械 / 电子 / 土木 / 材料 / 生物医学工程 / 建筑 |
| 艺术与设计 | 例如：视觉艺术 / 音乐 / 表演 / 影视 / 工业设计 / 交互设计 |
| 健康与公共服务 | 例如：护理 / 公共卫生 / 运动科学 / 教育 / 社会工作 |

每个孩子**恰好 3 个方向**，同一个孩子在同一类别只计一次、可计入多个类别，
所以 8 类的人数之和**可能超过孩子总数**——大屏上那句话就是这么写的，不是 bug。
0 人的类别连条形和释义一起不显示。

**刻意不设「跨学科」和「职业」两个桶。** 现场被问到就这么答：跨学科是结构属性不是学科，
会在不同批次落到不同的桶里；「职业」在中文语境里容易被读成职校，
而它想覆盖的方向本来都有明确的学科归属。
